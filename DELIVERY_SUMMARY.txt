================================================================================
                            QUICK REFERENCE
================================================================================

INSTRUCTIONS (10 Opcodes):
  PSH n      Push integer n
  ADD        Pop 2, push sum
  SUB        Pop 2, push difference
  MUL        Pop 2, push product
  PRN        Print top (no pop)
  SET 0-25   Pop to register (0=A, 1=B, ..., 25=Z)
  LD 0-25    Push from register
  JMP addr   Jump unconditionally
  JZ addr    Pop; jump if zero
  HLT        Halt

COMMANDS (In REPL):
  RUN        Execute buffered program
  CLEAR      Reset & clear buffer
  EXIT       Quit
  HELP       Show help

BUILD:
  make               Release build
  make debug         Debug build
  make clean         Clean artifacts
  ./ssvm --demo      Run examples
  ./ssvm             Interactive mode

================================================================================
                           SUPPORT & TROUBLESHOOTING
================================================================================

Compilation Issues:
  • "g++: command not found"
    → Install build tools
       Ubuntu/Debian: sudo apt install build-essential
       macOS: xcode-select --install

  • "C++17 not supported"
    → Update compiler: g++ --version
    → Use specific version: g++-11, g++-12, etc.

Runtime Issues:
  • "Stack overflow"
    → You pushed too many values
    → Add more arithmetic operations (ADD/SUB/MUL)

  • "Unknown label"
    → Check spelling matches exactly
    → Ensure label ends with colon: "LOOP:"

  • "Program runs but no output"
    → Add PRN instruction to print results
    → End program with HLT

More Help:
  → See README.md "Troubleshooting" section
  → Type "HELP" in REPL mode
  → Review example programs in main.cpp
